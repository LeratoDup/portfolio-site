## Getting Started

**Prerequisites:** Node.js 18+

```bash
git clone https://github.com/LeratoDup/portfolio-site.git
cd portfolio-site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Personalising the Site

| What to change                             | Where                                   |
| ------------------------------------------ | --------------------------------------- |
| Your links (GitHub, LinkedIn, email, site) | `lib/data.ts`                           |
| Your resume / CV                           | `public/resume.pdf` (replace this file) |
| Colours & layout                           | `tailwind.config.ts`                    |
| Page content & sections                    | `src/app/page.tsx`                      |

---

## Deployment

Deployed automatically via Vercel. To deploy your own fork:

1. Push to GitHub
2. Import the repo at [vercel.com/new](https://vercel.com/new)
3. Click **Deploy** — Vercel handles the rest

Every push to `main` triggers a redeployment.
